# Round 2 / fable-a — 用户可见中文话术冻结版（T3 / T3R / T4 / A0 / A2）

编制：Round 2 fable-a（claude-fable-5-thinking-xhigh）。地位：**冻结**。本文件是 ACCEPTANCE.md 第 1.5 条（「中文解释话术随规范冻结」）的执行稿：渲染输出必须能匹配模板结构且通过 `assert_non_clinical`。改模板先改本文件并留痕。

三套 T 族模板都冻结，但**只有消融胜者的那套随规范发布**；落选者的模板随其候选一起归档。

## 0. 全局规则（对所有模板生效）

1. **词汇单源**：`strong → 强`，`moderate → 中等`，`weak → 弱`。全仓库用户可见文本只许这三个词表示档位，A2 只消费不另造。
2. **数字纪律**：模板中出现的每个数字必须是用户可自行数出来的原始次数、自然日数、整数天数差或日期。日期写作「{某某某某} 年 {某} 月 {某} 日」。禁止小数、排名、人群比较。（T3R 模板按其规范允许「按半次计」的折算句——这正是它在消融 S4 阶段的可数性负债，如实保留，不粉饰。）
3. **禁词**：分数、评分、得分、打分、百分比、百分位、排名、指数、权重、系数、衰减、半衰期、算法名；任何拉丁字母与「%」；诊断词表全表（抑郁、焦虑症、人格障碍等，见 `assert_non_clinical` 词表，此处不复抄）。
4. **称呼**：第三人恒为「这个人」或「对方」，任何模板不得出现姓名、账号、原始会话名。
5. **时间口径**：一切「距今」表述实为「距 {as_of 日期}」；as_of 来自数据（调用方传入或数据内最大时间戳），不读墙钟。模板里写「到 {截止日期}」，不写「到今天」。
6. **收尾句**（每条边解释与每条推断解释必带）：「这是工作假设，你可以直接改。」
7. **透明句**（每套 T 族解释的首句）：「怎么算的：只统计次数和日期，不读聊天内容。」

占位符约定：`{次数}`=count，`{天数}`=days，`{折算次数}`=eff_count，`{折算天数}`=eff_days，`{最后日期}`=last_contact 的日期，`{截止日期}`=as_of 的日期，`{沉寂天数}`=age_days。

## 1. T3（无衰减，回退单体）

- **强**：「怎么算的：只统计次数和日期，不读聊天内容。你们互相都发过消息、有过一对一的交流，一共 {次数} 次，分布在 {天数} 个自然日里，达到强的标准（双方都发过、有一对一、不少于 10 次、不少于 3 个自然日）。这是工作假设，你可以直接改。」
- **中等（次数或天数未到）**：「你们互相都发过消息，共 {次数} 次，但{还不到 10 次 / 还没分布到 3 个自然日}，先算中等。这是工作假设，你可以直接改。」
- **中等（群聊封顶）**：「到目前为止你们只在群里说过话，没有一对一的记录，所以最多算中等。这是工作假设，你可以直接改。」
- **弱（单向）**：「到目前为止只有一方发过消息，先算弱。这是工作假设，你可以直接改。」
- **弱（往来太少）**：「你们的往来少于 3 次，先算弱。这是工作假设，你可以直接改。」
- **弱（无记录）**：「还没有你们往来的记录。」

## 2. T3R（分桶折算版；模板含折算句，为其规范本体）

- **通用首段（各档共用）**：「怎么算的：只统计次数和日期，不读聊天内容。近 90 天的往来按 1 次计，90 到 180 天的按半次计，180 到 360 天的按四分之一次计，再早的不计。你们各时段的原始条数都列在下面，可以自己核对。」
- **强**：「（首段）折算下来你们相当于 {折算次数} 次、跨 {折算天数} 天，双方都发过消息、有过一对一交流，达到强的标准。这是工作假设，你可以直接改。」
- **中等**：「（首段）折算下来你们相当于 {折算次数} 次，双方都发过消息，但{折算次数不到 10 次 / 折算天数不到 3 天 / 没有一对一记录}，先算中等。这是工作假设，你可以直接改。」
- **中等（群聊封顶）**：同 T3 群聊句，前接首段。
- **弱（折算后不足）**：「（首段）你们最近的往来太少，折算下来不到 3 次（更早的 {历史次数} 次已超过 360 天，不再计入），先算弱。历史记录仍会保留展示。这是工作假设，你可以直接改。」
- **弱（单向 / 无记录）**：同 T3 对应句。
- **附加句（last_contact 距 as_of 超过 180 天时，任何档都追加）**：「你们最近半年没有往来，最后一次是 {最后日期}。」

## 3. T4（整数降档版；全模板无折算、无分数）

- **强（未触发降档）**：「怎么算的：只统计次数和日期，不读聊天内容。你们互相都发过消息、有过一对一的交流，一共 {次数} 次，分布在 {天数} 个自然日里，最近一次是 {最后日期}，达到强的标准。这是工作假设，你可以直接改。」
- **中等（原本中等，未降档）**：同 T3 的两条中等句（次数天数未到 / 群聊封顶）。
- **中等（由强降下）**：「按次数和天数，你们本来达到强的标准（共 {次数} 次、跨 {天数} 个自然日、有一对一记录），但最近一次往来是 {最后日期}，到 {截止日期} 已经 {沉寂天数} 天没有联系，超过半年，先算中等。只要重新来往，就会回到强。这是工作假设，你可以直接改。」
- **弱（由中等降下）**：「你们互相发过消息共 {次数} 次，本来算中等，但最近一次往来是 {最后日期}，到 {截止日期} 已经 {沉寂天数} 天没有联系，超过半年，先算弱。这是工作假设，你可以直接改。」
- **弱（沉寂超一年，直接封弱）**：「你们最近一次往来是 {最后日期}，到 {截止日期} 已经 {沉寂天数} 天没有联系，超过一年（360 天），先算弱。过去的 {次数} 次往来仍会保留展示，重新来往就会回升。这是工作假设，你可以直接改。」
- **弱（单向 / 往来太少 / 无记录）**：同 T3 对应句。

复核路径说明（进规范附注，不进用户界面）：用户核对 T4 只需要三件事——数消息条数、数日期个数、看最后一次的日期距截止日期差几天。全程无乘法。

## 4. A0（问卷 + 纠正锁）

- **问卷来源（中等档）**：「这一条来自你 {某年某月某日} 的问卷回答（{依据条数} 条依据），先按中等对待。这是工作假设，你可以直接改。」
- **本人纠正（强档，锁定）**：「这一条来自你本人的纠正，已锁定：之后的推断只会被记录，不会改动它。」
- **锁定后收到新推断（审计/详情页）**：「你已锁定这一条。{某年某月某日} 有一条新的推断被记录在案，但没有改动你的设定。」
- **未作答的轴**：「这一条还没有依据，保持未知。」
- **无证据推断被拒（开发者/审计可见，仍须非临床）**：「这条推断没有附带任何依据，未被接受。」

（轴位置词「偏低 / 两可 / 偏高 / 未知」的最终措辞沿用 goal1 `profile_axes.rs` 现有文案，不在本文件另造第二套；若 Round 3 要改，先改这里再改代码。）

## 5. A2（统计式人事摘要；band 纯消费者）

五类句子，每句携带 `evidence_ids`，构造期过 `assert_non_clinical`。

- **P1 总量**：「一共 {次数} 次往来，分布在 {天数} 个自然日、{会话数} 个会话里。」
- **P2 方向**（互斥分支，阈值 2:1）：
  - out = 0：「都是对方在说。」
  - in = 0：「都是你在说。」
  - out > 2 × in：「多数时候是你先开口。」
  - in > 2 × out：「多数时候是对方先开口。」
  - 其余：「两边说得差不多。」
  （后两个分支中「都是你在说」「多数时候是对方先开口」是对 CANDIDATE_SPEC 三分支的对称补全，Round 2 冻结于此。）
- **P3 场合**：有一对一记录 →「有过一对一交流。」；仅群聊 →「只在群聊里见过。」
- **P4 近因**：「最近一次是 {最后日期}。」；last_contact 距 as_of 超过 180 天 → 追加「你们最近半年没有往来。」（只引最近一条证据。）
- **P5 归档**：「按上面的计数，这段关系归在『{强/中等/弱}』一档；这是工作假设，不是对这个人的判断。」

约束重申：P5 的档位词来自 T 族胜者产出的 band，A2 不得自带第二套阈值；P4 的 180 天与 T4 的降档常量是**同一个常量**（`DORMANT_NOTE_DAYS = DEMOTE_ONE_BAND_DAYS = 180`），进 `docs/algorithms/` 常量表单点定义——若 T4 胜出，摘要句与档位变化天然自洽（说「最近半年没有往来」的边必然不是强）。

## 6. 模板验收断言（供实现者写成测试）

1. 每个模板渲染结果通过 `assert_non_clinical`，且不含第 0.3 条禁词与任何拉丁字母。
2. T4 与 T3 的全部模板中不出现「折算」「半次」「四分之一」及任何非整数数字。
3. 每个数字占位符可由输入观测直接重算（次数=条数、天数=去重日期数、沉寂天数=日期差整数天）。
4. 任何模板不出现「今天」「现在」字样（时间口径见第 0.5 条）。
5. band 词只出现「强 / 中等 / 弱」三种，且与 `SupportedBand` 一一对应。
