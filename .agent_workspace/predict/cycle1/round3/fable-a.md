## 0. 冻结了什么、凭什么冻结

冻结对象是三样：**(a) 候选目录**（默认轨 + 对照轨 + 具名备选 + 陪跑位 + 墓碑区），**(b) 每个候选的主杀线与晋级/翻案条件**，**(c) 测试日前置缺口清单**。
不冻结的：杀线里待扫的常量数值（按「先登记候选集、扫完写死、禁止倒填」程序处理）、REAL 夹具的具体日志（本机产生，不出网）。

入选判据（全部沿既有裁决，此处只汇总为终版四条）：

1. **数据面**：输入 ⊆ 四个数据面（前台会话 exe+时长+起止、T4D 冻结字段、A0 轴只读、有同意的 derived 计数）。多一样即墓碑（fable-b 十问 #1）。
2. **可数性**：输出是闭集 token + 整数支持计数；排序算术可以不是展示句，但**排序规则必须能被展示句完整陈述**（fable-a R2 裁决线）。禁浮点权重、禁概率上屏、禁分数百分位（G10 / D22）。
3. **可遗忘**：不变式 F 按 R2 综合的加固版执行——只在 `evictions == 0` 时断言逐桶相等；删除事件走**有界局部重算**（≤3 个相邻 run，opus-a 引理三）；有损变换只许在读路径；外加 F′（候选消费的每个输入字段遗忘后必须被删除或不可读）。
4. **可证伪**：每个候选有具名主杀线与专属夹具；`inconclusive` 一律按不通过处理；「打不赢更简单前身」即出局。

## 7. 共同纪律（冻结引用，不再复述全文）

1. **输出契约**：token + 整数支持 + 弃权集（`consent_off / no_data / thin_support / axis_locked`）；并列一律 `app_id` 字典序；「猜」不是弃权的替代品。
2. **训练纪律**：只有在线整数计数，摊销 O(1)，`TOPK_APPS=256` / 行内 TOPK 逐深度独立；判定是纯函数 `(counts, context, as_of) -> tokens`，禁读墙钟。
3. **评测协议**：prequential（先冻结预测、再揭晓、恰好更新一次）；段按同意/锁屏/来源错误切开，禁跨段转移；指标只有 top-1 / top-3 / 弃权率三项，弃权计入分母；先整数分子分母后派生小数；两张表分刊（§1/§2）；全部指标只在评测器内部，不上屏、不进审计正文、不进档案。
4. **泄漏防线**：shuffle 负对照（P1≈P0，种子与 ε 预注册）+ 前缀因果不变式（同前缀异后缀 ⇒ 该点输出逐字节相同，零容差）。
5. **常量纪律**：待扫常量（`MIN_ROW_SUPPORT_3∈{8,10,12}`、P4 半衰期三档、P7 阈值组）先登记候选集与登记时间，扫完写死，禁止事后倒填；半衰期选档与窗口大小是同一个决策（`W = h·(1+⌊log2 CAP⌋)`）。
6. **渲染纪律**：证据句只含原始整数；禁诊断词 denylist、禁「比你平时多」类基线措辞（μ 分解未获批）、禁褒贬人格措辞；用户纠正是锁；预测与档案是单向玻璃（读不写）。
