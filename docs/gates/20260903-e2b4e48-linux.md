## 环境坑（首次跑出来的；修法已落 `justfile`，见 `git log -- justfile`）

1. **`NODE_ENV=production` 会让 ui-test 全灭**（72 失败 `React.act is not a function`）。react-dom 在 production 下不导出 `act`。本机 shell 全局设了 `NODE_ENV=production`。修法：`justfile` 的 `ui-test` / `ui-lint` 显式 `NODE_ENV=test` / `env -u NODE_ENV`，不能依赖跑门禁的人的 shell。
2. **pnpm 必须 ≥10**（`package.json` `engines.pnpm >=10`，`packageManager pnpm@10.15.0`）。装 9 直接 `ERR_PNPM_UNSUPPORTED_ENGINE`。
3. **`Wizard.test.tsx > 每一项能力在开始使用之前都是关的` 在全量并发下偶发失败**（一次全量跑 1/161 失败，单文件重跑 13/13 过，3.3s）。jsdom + 4 核争抢下的超时类 flake。修法：给该测试加 timeout 或 `vitest --poolOptions.threads.maxThreads=2`；写进 P0。
4. **`--all-features` 是白花的 18 分钟。** 工作区无任何 crate 声明 `[features]`（只有 `apps/desktop/src-tauri` 有，且不在 workspace）。`--all-features` 在 workspace 上等价于无，却导致 fingerprint 不同 → OpenSSL 二次源码编译。P0 从 `justfile` lint 里删掉 `--all-features`，预期 clippy 降到 ~3 分钟（热缓存）。
