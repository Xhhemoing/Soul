# ADR-003：长期战略指引与近期验证收敛

日期：2026-10-23（America/Los_Angeles）。状态：采纳作者本次长期计划更新要求；具体执行与敏感操作分别按授权推进。决定索引：D112。

## 背景与依据

作者提供《Soul长期战略与近期验证方案_v1.2.docx》和 `2026-10-23-long-term-strategy.md`，明确要求“更新项目的长期计划，记住后续严格按照这两份文件为指引，同时注意不要过多的冒烟测试、写入哈希、死磕一块地方”。本次授权覆盖战略文档、项目执行约束与记忆更新。

两份输入原文均标为尚未采纳的提案。以本次用户请求为采纳战略指引的依据，而不是以附件的“建议授权”代替真实数据、出网、研究、远端设置或发布许可。原件与核对记录见[战略计划来源](../plans/2026-10-23-long-term-strategy.md#12-来源与本次文档核对)。

## 决定

- 采用[长期战略与近期验证方案](../plans/2026-10-23-long-term-strategy.md)，仓库修订为 v1.3。三条长期目标保持：个人数字分身、商业产品、行为建模研究；按 S1 回复消息、S2 整理琐事、S3 分析人与事、S4 推敲选择、S5 回顾记忆组织场景。
- 近期优先 S1 使用验证准备与闭环，只细化两个周期及其后的一个决策点；当前验证尚未启动。该排序替代 D107 的研究优先排期，不删除 D107 已有实现、安全维护、失败、缺测和未完成项。数据与模型系列研究继续暂停，新实验后置。
- ROADMAP 保留长期能力、正式阶段依赖和旧协议；近期排序以新计划为准，当前进展只在 STATUS 维护。正式 Goal 1/Goal 2、平台验收和产品锁边界不因战略采纳而关闭或豁免。
- S1-a 使用现有能力、S1-b 编辑差异推断、S1-c 反馈记录分开。规划采用 T1/T3，区分请求模式与实际来源，降级不冒充 T3 成功；T1 不评消息内容事实，缺测不填零，未评不记为无错误。跨模式差异不证明范围偏好对端点有效。
- 反馈设计按最小字段、独立用途、不存正文或对象关联、相关遗忘整批删除处理；真实记录的目录与使用范围尚须具体明确。本次没有真实材料读取、端点调用、研究恢复或远端修改授权。
- 冒烟只覆盖必要启动/接线确认；无新候选、环境或问题时不重复。按风险执行实际主路径、缺陷复现、必要回归与已有检查，不让预检代替验证，也不删现有安全措施。
- 不照搬附件中固定旧 SHA、最低磁盘空间阈值、全量构建和 CI/main 对齐的一揽子开发前置。记录实际候选与 dirty；资源问题按具体阻塞处理。默认不新增哈希台账、冻结 contract、baseline 或 gate，例外仍须满足 AGENTS 的逐项理由。
- 每项任务明确时间盒、产物和停止条件；问题已回答即收口，无增量证据或到期则记录未决与恢复条件，后置或转向无依赖的已授权工作。安全阻塞仅阻断相关路径，不能靠超时跳过。
- 维持最多两名实现者与一名独立评审者，共享语义串行；热点按真实冲突处理。无场景需求的 API 扩展后置，安全修复与当前场景依赖按授权推进。

## 未由本决定授予的权限

原方案 D-S2 的 Actions/分支保护/合并操作、D-S5 的真实白名单材料、D-S6 的真实反馈使用安排，以及 D-S7/S1-b 新能力、D-S8 具体研究恢复，不能从“采纳指引”推定为已获执行许可。操作前只补齐确实缺少的范围，已有授权不重复询问。具体对照见计划 §11。

计划日期与约 20 次观察均是参考，不是自动启动、样本硬门槛或效果证明；不为凑数量、过线或优化单点无限延期。文件整理、研究恢复和外部交付是不同任务，本次只交付文档与执行指引。

## 影响与验证

PRODUCT_LOCK 只调整近期定位和导航，不扩展功能、真实数据或出网范围。AGENTS/operations 固化稳定执行规则；PLAN_INDEX/ROADMAP 指向同一计划。文档核对、独立只读审查及未运行范围保存在计划 §12 的本机证据目录；未执行代码测试、构建、真实使用或远端 CI。
