# 用户可见中文话术（冻结版，随 ALGO_FROZEN 发布）

编制：Round 3 fable-a，承接 Round 2 冻结稿（`round2/fable-a/COPY_ZH.md`）。本文件只收**胜者模板**：**T4D**（发布默认）、**T4**（档内回退形态，随规范待命）、**A0**、**A2**。落选者（T3 / T3R）的模板随其墓碑归档于 Round 2 稿，不再随规范发布。渲染输出必须能匹配本文件模板结构且通过 `assert_non_clinical`；改模板先改本文件并留痕。

## 0. 全局规则（对所有模板生效）

1. **词汇单源**：`strong → 强`，`moderate → 中等`，`weak → 弱`。全仓库用户可见文本只许这三个词表示档位，A2 只消费不另造。
2. **数字纪律**：模板中出现的每个数字必须是用户可自行数出来的原始次数、自然日数、整数天数差或日期。日期写作「{某某某某} 年 {某} 月 {某} 日」。禁止小数、分数折算、排名、人群比较。（T3R 落选后，全部发布模板再无任何非整数数字。）
3. **禁词**：分数、评分、得分、打分、百分比、百分位、排名、指数、权重、系数、衰减、半衰期、算法名；任何拉丁字母与「%」；诊断词表全表（见 `assert_non_clinical` 词表，此处不复抄）。
4. **称呼**：第三人恒为「这个人」或「对方」，任何模板不得出现姓名、账号、原始会话名。
5. **时间口径**：一切「距今」表述实为「距 {as_of 日期}」；as_of 来自数据（调用方传入或数据内最大时间戳），不读墙钟。模板里写「到 {截止日期}」，不写「到今天」。
6. **收尾句**（每条边解释与每条推断解释必带）：「这是工作假设，你可以直接改。」
7. **透明句**（每套边解释的首句）：「怎么算的：只统计次数和日期，不读聊天内容。」T4D 版在其后追加半句「判档只看你们一对一的往来。」

占位符约定：`{次数}`=全部往来条数，`{天数}`=全部活跃自然日数，`{一对一次数}`=一对一往来条数，`{一对一天数}`=一对一活跃自然日数，`{群聊次数}`=群里同场往来条数，`{最后日期}`=任一场地最后一次往来的日期，`{截止日期}`=as_of 的日期，`{沉寂天数}`=整数沉寂天数。

## 1. T4D（发布默认：门槛全在一对一计数上，降档时钟读任一场地）

- **强（未降档）**：「怎么算的：只统计次数和日期，不读聊天内容；判档只看你们一对一的往来。你们一对一互相都发过消息，一共 {一对一次数} 次，分布在 {一对一天数} 个自然日里，最近一次往来是 {最后日期}，达到强的标准（一对一互相发过、不少于 10 次、不少于 3 个自然日）。这是工作假设，你可以直接改。」
- **中等（一对一次数或天数未到）**：「你们一对一互相都发过消息，共 {一对一次数} 次，但{一对一还不到 10 次 / 一对一还没分布到 3 个自然日}，先算中等。这是工作假设，你可以直接改。」
- **中等（由强降下）**：「按一对一的次数和天数，你们本来达到强的标准（一对一共 {一对一次数} 次、跨 {一对一天数} 个自然日），但最近一次往来是 {最后日期}，到 {截止日期} 已经 {沉寂天数} 天没有联系，超过半年，先算中等。只要重新来往，就会回到强。这是工作假设，你可以直接改。」
- **弱（由中等降下）**：「你们一对一互相发过消息共 {一对一次数} 次，本来算中等，但最近一次往来是 {最后日期}，到 {截止日期} 已经 {沉寂天数} 天没有联系，超过半年，先算弱。这是工作假设，你可以直接改。」
- **弱（沉寂超一年，直接封弱）**：「你们最近一次往来是 {最后日期}，到 {截止日期} 已经 {沉寂天数} 天没有联系，超过一年（360 天），先算弱。过去的 {次数} 次往来仍会保留展示，重新来往就会回升。这是工作假设，你可以直接改。」
- **弱（只在群里说过话）**：「到目前为止你们只在群里说过话（同场往来 {群聊次数} 次），还没有一对一的记录，先算弱。群里的往来仍会保留展示。这是工作假设，你可以直接改。」
- **弱（一对一往来太少）**：「你们有过 {次数} 次往来，但一对一的只有 {一对一次数} 次，少于 3 次，先算弱。这是工作假设，你可以直接改。」
- **弱（一对一单向）**：「你们一对一的记录里只有一方发过消息，先算弱。这是工作假设，你可以直接改。」
- **弱（无记录）**：「还没有你们往来的记录。」

复核路径说明（进规范附注，不进用户界面）：用户核对 T4D 只需要四件事——数一对一消息条数、数一对一日期个数、看最后一次往来（任何场合）的日期距截止日期差几天、确认双方在一对一里都发过。全程无乘法。降档句里的「最近一次往来」刻意含群聊：群里昨天还说过话的关系不会因一对一暂歇而降档（DECISION.md 第 4.3 节定价）。

- **中等（由强降下）**：「按次数和天数，你们本来达到强的标准（共 {次数} 次、跨 {天数} 个自然日、有一对一记录），但最近一次往来是 {最后日期}，到 {截止日期} 已经 {沉寂天数} 天没有联系，超过半年，先算中等。只要重新来往，就会回到强。这是工作假设，你可以直接改。」
- **弱（由中等降下）**：「你们互相发过消息共 {次数} 次，本来算中等，但最近一次往来是 {最后日期}，到 {截止日期} 已经 {沉寂天数} 天没有联系，超过半年，先算弱。这是工作假设，你可以直接改。」
- **弱（沉寂超一年，直接封弱）**：「你们最近一次往来是 {最后日期}，到 {截止日期} 已经 {沉寂天数} 天没有联系，超过一年（360 天），先算弱。过去的 {次数} 次往来仍会保留展示，重新来往就会回升。这是工作假设，你可以直接改。」

- **弱（无记录）**：「还没有你们往来的记录。」

## 3. A0（问卷 + 纠正锁）

- **问卷来源（中等档）**：「这一条来自你 {某年某月某日} 的问卷回答（{依据条数} 条依据），先按中等对待。这是工作假设，你可以直接改。」
- **本人纠正（强档，锁定）**：「这一条来自你本人的纠正，已锁定：之后的推断只会被记录，不会改动它。」
- **锁定后收到新推断（审计/详情页）**：「你已锁定这一条。{某年某月某日} 有一条新的推断被记录在案，但没有改动你的设定。」
- **未作答的轴**：「这一条还没有依据，保持未知。」
- **无证据推断被拒（开发者/审计可见，仍须非临床）**：「这条推断没有附带任何依据，未被接受。」

（轴位置词「偏低 / 两可 / 偏高 / 未知」的最终措辞沿用 goal1 `profile_axes.rs` 现有文案，不另造第二套；要改先改这里再改代码。A1 升档规则 TwoKindsAcrossDays 是 A0 内部机制，无独立话术；v0.1 单一来源下永不触发。）

## 4. A2（统计式人事摘要；band 纯消费者）

六类句子，每句携带 `evidence_ids`，构造期过 `assert_non_clinical`。

- **P1 总量**：「一共 {次数} 次往来，分布在 {天数} 个自然日、{会话数} 个会话里。」
- **P1b 场合分列**（Round 3 新增，T4D 供数）：「其中一对一往来 {一对一次数} 次，群里同场 {群聊次数} 次。」——只渲染 T 族算好并随 `TieScore` 携带的两个数；任一数缺席则整句不出现。**A2 禁止自行从证据推导分列**（推导即第二意见）。
- **P2 方向**（互斥分支，阈值 2:1）：
  - 对方发出为 0：「都是你在说。」
  - 你发出为 0：「都是对方在说。」
  - 你发出多于对方两倍：「多数时候是你先开口。」
  - 对方发出多于你两倍：「多数时候是对方先开口。」
  - 其余：「两边说得差不多。」
- **P3 场合**：有一对一记录 →「有过一对一交流。」；仅群聊 →「只在群聊里见过。」
- **P4 近因**：「最近一次是 {最后日期}。」；最后往来距 as_of 达到 `DEMOTE_ONE_BAND_DAYS`（闭区间 `>=`，与降档同一常量）→ 追加「你们最近半年没有往来。」（只引最近一条证据。）
- **P5 归档**：「按上面的计数，这段关系归在『{强/中等/弱}』一档；这是工作假设，不是对这个人的判断。」

约束重申：P5 的档位词来自 T4D 产出的 band，A2 不得自带第二套阈值；P4 的 180 天与降档常量是**同一个常量**（`DORMANT_NOTE_DAYS = DEMOTE_ONE_BAND_DAYS = 180`，单点定义见 DECISION.md 常量表）。T4D 的降档时钟与 P4 读同一个「任一场地最后往来」，因此不变式免费成立：出现「最近半年没有往来」句的边必然已降档，永远不是强。

## 5. 模板验收断言（随 `crates/soul-algo` 写成测试）

1. 每个模板渲染结果通过 `assert_non_clinical`，且不含第 0.3 条禁词与任何拉丁字母。
2. 全部发布模板中不出现「折算」「半次」「四分之一」及任何非整数数字。
3. 每个数字占位符可由输入观测直接重算：{一对一次数}=一对一消息条数，{一对一天数}=一对一去重日期数，{群聊次数}=群消息条数，{沉寂天数}=日期差整数天。
4. 任何模板不出现「今天」「现在」字样（时间口径见第 0.5 条）。
5. band 词只出现「强 / 中等 / 弱」三种，且与 `SupportedBand` 一一对应。
6. **T4D 门槛引用一致性**：凡判档消费的是一对一计数，模板句必须引用 {一对一次数}/{一对一天数}，不得引用总量冒充；总量只许出现在 A2 的 P1 与 T4D 的「保留展示」句。
7. A2 的 P1b 句在 `TieScore` 分列字段缺席时不渲染；A2 源码不得包含从证据行重算分列的路径。

## 6. 降档时钟投影（AD-13；A2 摘要之后的追加句）

加性一节：第 1–5 节一个字不动，A0/A2/T4D/T4 的模板与判档规则原样。这里只把 T4D 已经在用的两个天数常量和边上已经写好的日期换算成一个日期，说出「再不联系，哪一天这一档会变」。它不是学习出来的预报，也不新增任何阈值——同一条时钟，向后读一次而已（AD-9）。

口径（除第 0 节全局规则外另加）：

1. **常量单点**：只读 `DEMOTE_ONE_BAND_DAYS` 与 `FORCE_WEAK_DAYS`（定义见 DECISION.md 常量表）。产品 crate 不得再写第三处字面量（D52）。
2. **不读墙钟**：as_of 由调用方传入（边上的 `as_of`），与第 0.5 条同一口径。
3. **闭区间**：沉寂天数 `>=` 阈值当天即降档，所以模板写「从那天起」，不写「超过之后」（D60 同一写法）。
4. **档位词写死**：强 / 中等 / 弱 直接写在模板里，没有 `{下一档}` 这类占位符——一条模板只说一次降档，读的人不必自己推下一档是什么。
5. **收尾句**：四条都带第 0.6 条收尾句「这是工作假设，你可以直接改。」

占位符补充：`{降档日期}`=任一场地最后一次往来 + `DEMOTE_ONE_BAND_DAYS` 天所落的那一天；`{封弱日期}`=同一起点 + `FORCE_WEAK_DAYS` 天所落的那一天；`{一对一沉寂天数}`=一对一最后一次往来距 as_of 的整数天数。

- **投影 1（强 → 中等）** `personnel.projection.strong_to_moderate`：「如果你们一直没有新的往来，到 {降档日期} 就满 {天数} 天没有联系，从那天起这一档会从「强」降到「中等」。在那之前只要再聊起来，这一档就不会降。这是工作假设，你可以直接改。」
- **投影 2（中等 → 弱）** `personnel.projection.moderate_to_weak`：「如果你们一直没有新的往来，到 {降档日期} 就满 {天数} 天没有联系，从那天起这一档会从「中等」降到「弱」。在那之前只要再聊起来，这一档就不会降。这是工作假设，你可以直接改。」
- **投影 3（封弱）** `personnel.projection.forced_weak`：「如果你们一直没有新的往来，到 {封弱日期} 就满 {天数} 天没有联系，从那天起这一档会算「弱」。过去的往来仍会保留展示，重新来往就会回升。这是工作假设，你可以直接改。」
- **投影 4（现在靠群里撑着）** `personnel.projection.group_maintained`：「你们一对一已经 {一对一沉寂天数} 天没有单独说过话；降档看的是任一场地的最近一次往来，所以这一档现在是靠群里的往来维持的。等群里也安静下来，这一档才会跟着往下降。这是工作假设，你可以直接改。」

什么时候不出现（抑制，缺一不可）：

- 已经是**弱**——最弱的一档没有下一档可投影；
- 边被**用户锁定**——生效档是用户的裁决，机器的时钟不再决定它（GC-9a 同一理由）；
- **没有可引的证据行**——无证据不落一句（AC-16）；
- 沉寂已经**满 `FORCE_WEAK_DAYS`**——该发生的都发生了，投影没有可说的；
- 边上**没有 as_of 或最后往来读不出来**——旧行不假装知道日期（与 P1b 同一取舍）。

哪几条一起出现：强档出投影 1 与投影 3（先降一档，再封弱）；中等且尚未降档出投影 2；中等且已经降过一档（沉寂 `>=` `DEMOTE_ONE_BAND_DAYS`）出投影 3。投影 4 与上面互不排斥，但只在「一对一沉寂 `>=` `DEMOTE_ONE_BAND_DAYS` 且任一场地沉寂 `<` `DEMOTE_ONE_BAND_DAYS`」时出现。

本节验收断言（随 `crates/soul-draft/tests/projection_sentences.rs` 落地）：

1. 四条模板渲染结果过 `assert_non_clinical`，不含第 0.3 条禁词与任何拉丁字母，且都以第 0.6 条收尾句结尾。
2. 沉寂 179 天出投影，180 天当天该档的「还会降」那一条不再出现（闭区间）；359 天仍出封弱句，满 360 天整节消失。
3. 锁定边、无证据边、弱档边一句投影都不出。
4. 产品 crate 不出现 180 / 360 字面量（D52，由 `day_constants_agree.rs` 扫）。

## 7. 已锁定的轴又被答了一次（D46 / G2；问卷收据上的追加句）

加性一节：第 1–6 节一个字不动，A0 的判档与纠正锁规则原样。这里补的是第 3 节留白的一件事——问卷随时可以再答，而已锁定的轴不会被再答移动（`soul-profile` 的 `IntakeSkip::AxisLockedByUser`，D46），收据因此带回若干条「记下了，但没有生效」的答案，在这之前没有一句用户读得懂的话可以说明它们。第 3 节那条「锁定后收到新推断」说的是机器推断，不是用户自己的再答，两者不通用。

口径（除第 0 节全局规则外另加）：

1. **机器词不上屏**：核心回的 `axis_locked_by_user` 是取句用的键，不是话。屏幕上任何位置都不得出现这个词本身。
2. **数字**：`{条数}` 是这一次没有生效的答案条数，用户自己数得出来（第 0.2 条）。
3. **兜底**：这一版没有对应句子的理由走兜底句，仍不许把键印出来。
4. **空则不出**：收据里没有被拒的答案时，这一段一个字都不出现——没有发生的事不写在屏幕上。
5. **不承诺解锁**：锁没有「解开」这个动作，用户改方向的办法就是在那条轴上再按一次，所以模板只指回那条轴，不提第二条路径。

- **计数前缀** `profile.intake.ignored_count`：「这一次有 {条数} 条没有改动档案。」
- **落在已锁定的轴上** `profile.intake.axis_locked_by_user`：「你纠正过的轴还锁着：这几条已经记进证据里，但没有改动那几条轴的方向。想改方向，就在上面那条轴上直接按你要的那一端。」
- **兜底（理由这一版没有对应句子）** `profile.intake.ignored_other`：「这几条已经记进证据里，但档案没有跟着动。」

同一节顺带钉住再答那一段的说明：**「以你最后说的为准」只对没锁的轴成立**。锁上的轴以用户的纠正为准，再答一次只记证据，不改方向；界面说明句不得把最后一句话当成对全部五条轴的承诺。

本节验收断言（随 `apps/desktop/src/routes/Profile.test.tsx` 落地）：

1. 收据带回被拒答案时，屏幕上出现条数与本节对应的那句话，且句子逐字取自本文件。
2. `ignored` 为空时这一段不渲染。
3. 任何一次渲染里都找不到 `axis_locked_by_user` 这个词；理由不认得时出的是兜底句。
4. 再答那一段的说明句里，「以你最后说的为准」带着「没锁」的限定，并说明锁上的轴再答只记证据。
