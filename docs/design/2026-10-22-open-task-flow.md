## 最小实现

一次模型请求生成 0–8 个自由表述的必要信息，每项包含任务原文引句、状态、完整支持组或冲突来源；同时提取各来源主体、范围、时间及明确更正关系。字段未提供时输出 null，不使用猜测或当前日期填充。来源字段值必须来自对应可见原文的连续子串；更正边须有当前来源原文引句且指向明确来源 ID。引句存在只证明出处，不证明语义正确，后者另行评价。

运行时先验证结构、引用、不可读边界和原文引句，再将模型自身的 needs 投影为旧 `Input/Prediction`，复用 BM25/分组/MMR、完整 AND/OR 支持组选材和真实 Session 准备。模型提取内容明确标注为机器提取，附在保留的原始来源正文之后，不伪装成额外权威事实。零需求独立返回无需准备，不强迫发明占位需求。既有 8 项容量上限和来源/预算检查保持，超限保留失败。

## 评价与验收

gold 在模型调用前编写并独立检查；原文主运行只读 input 和模型结果。自由表述需求不能按固定文字或预先 ID 评分：运行之后，由本会话和独立评审 agent 按任务含义将预测需求与 gold 原子需求进行语义匹配；这不是外部人工标注或用户验收。允许等价拆分/合并，不因措辞不同判错；遗漏、重复、额外必要项单列。该匹配只用于事后计分，不回流运行、选材或提示词。

模型前确定评分口径：需求召回以被覆盖的 gold 原子项计数；预测项不能对应任何必要信息时记额外项，等价拆分与合并不自动扣分。状态正确须覆盖对应 gold 状态；支持组逐组检查是否包含完整的有效 AND 组，冲突须保留足够的相反证据。来源字段按原文事实语义复核，允许合理跨度和 subject/scope/time 字段划分差异；非空参考不是唯一写法，但遗漏影响适用性的主体、范围、时间或错误更正关系须记错。结构失败仍计入全部任务分母，单独保留能读出的局部诊断，不用局部正确冲抵运行失败。严格全链通过须需求、来源信息、状态/证据、动作全部正确，且可继续任务最终保留完整事实组；无信息需求任务单列。原文主结果与预整理对照分开报告。

分别统计需求识别、来源字段/更正关系、必需项状态与证据充分性、最终动作、错误继续、无谓阻断、最终完整事实覆盖。固定四/八条继续作为同池材料覆盖对照，不作为语义诊断算法。零需求任务单列；字节收益仅比较同任务、同事实覆盖的实际准备结果。报告模型 HTTP 与本地准备的计时边界；实际成本包括本轮原文与预整理条件全部调用。
