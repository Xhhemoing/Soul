# 自主拍板记录

作者 2026-08-24 声明：除已给出的产品方向外，其余问题可自主决定。本文件记录拍板，避免后续子代理重开方向战。

| ID | 问题 | 决定 | 理由 |
|---|---|---|---|
| D1 | Soul 是助手还是数字复刻 | 数字复刻为灵魂层，助手为代理层，复刻是本体 | 作者定义是电子版的你，不是通用助手 |
| D2 | 要不要默认云端 | 默认全本地；云端深度分析显式开启 | 作者要 Windows 本地优先，云端是后期能力 |
| D3 | 社交数据怎么进来 | 官方导出 / OAuth / 用户导入，禁止爬虫 | 合法、稳定、可审计 |
| D4 | 能否自动回消息 | v0.1 只起草不发送 | 人格复刻尚未被用户校准前，代发不可逆 |
| D5 | 心理模型是否临床 | 否。工作模型 + 证据 + 用户纠正 | 避免医疗声称 |
| D6 | 手机何时做 | Android 在 v0.3，iOS 更后 | Windows 本地先跑通闭环 |
| D7 | 研究数据如何用 | 本机事件库 + 脱敏导出；与助手出网分离 | 满足研究目标且不偷渡原始生活数据 |
| D8 | v0.1 是否要真预测模型 | 只要事件 schema、特征清单、导出和离线入口 | 先有可研究的数据，再谈模型效果 |
| D9 | 技术栈 | Tauri2 + Rust + React；预测预留 Python sidecar | 常驻、沙箱、打包适合 Windows |
| D10 | 文件整理为何仍在 MVP | 作为代理层安全执行的垂直证明，不是产品定义 | 电脑问题处理需要一条可测的写路径 |
