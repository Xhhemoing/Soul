# BeadFlow — 拼豆辅助产品规划

状态：2026-08-25 由用户确认，作为本专属线的产品原则。  
本文件只约束 `apps/bead/**` 与 `crates/bead-core/**`（隔离树）。  
**不是** Soul 的第二份 `PRODUCT.md`。Soul 仍以 `docs/PRODUCT_LOCK.md` 为唯一权威（D27）。

## 总目标

方便快捷地辅助整个拼豆流程：获取豆图、备料、沉浸式步骤指引、社交宣传。

## 界面

### 0.「+」创作与导入

快速入口：上传转豆图、从画廊/自己的创作选择、空白项目、导入已有豆图或项目库。

### 1. 灵感（Explore）

官方社区 + 个人面板。

- 个人条：拼豆进度、待办、收藏；兼快速入口。
- 发现流：推荐、热门标签（二次元、像素游戏、立体拼豆、节日限定）。
- 图纸详情：难度、颗粒总数、预估耗时、板型、配色清单；一键加入待拼 / 转入工作台。
- 创作者主页：作品集、被拼打卡数、一键 Fork（二创改色）。

### 2. 拼装台（Workspace）

当前项目中心（类 DAW / IDE 活跃工作区）。

- 正在拼：置顶最近项目、进度条、用时、「继续拼豆」。
- 草稿与设计：未开始或编辑中的自定义图纸。
- 历史完工：记录、用时、成品质感预览。

### 3. 资产（Inventory）

色号库存、缺口预警、补货清单、近似色替代。

## 功能

### 获取豆图

- 上传图片生成（像素图 / 正常图两套算法）。
- 已有创作、公共画廊、空白项目、导入分析、导入项目库。

图像转换：

- 智能识别是否为像素图。
- 像素图：按图中像素块识别。
- 正常图框定：固定板子大小；按图片比例自适配；固定展示框手动缩放后确定切分。

品牌色板映射：Lab + CIEDE2000。可选 Floyd–Steinberg 抖动。标准板型（含 28×28、56×56、六角、圆板）与多板拼接。

已有豆图 / 实物逆向：透视矫正 + 网格提取。

像素编辑器：对称、油漆桶、拾色器、色号替换、颜色统计。

格式：`.png` `.jpg` `.pat` `.gamedev` `.beadproj`。

### 备料

自动统计色号/名称/颗数；库存对比预警；ΔE&lt;3 近似替代。

### 沉浸式拼豆指引（核心卖点）

黑 / 白 / 自定义背景；透光底图 1:1 物理尺寸；悬浮控制球；进度与计时（BPM、里程碑）。

四种步骤模式：

1. 单色逐个击破（Color-by-Color）
2. 分块拼装（Board-by-Board / 28×28 tile）
3. 结构支撑优先（Outline → Infill，连通分量）
4. 逐行扫描（Row-by-Row）

语音/手势为可选，不进 v0。

## v0 范围（本线先做）

本机可用的闭环：转豆图 → 清单 → 四种指引 → 本地项目。  
Explore 用 fixture 画廊，不做真实社交后端。  
不改 Soul 锁、不进 `apps/desktop`、不进 `crates/soul-*`。
