## 0. 结论

WP-B01/B03 与 PLAN.md 方向一致、范围合理（v0 不做六角/圆板、多板拼接、实物逆向）。但存在 **8 处契约缺口（G1–G8）**：不钉死则 B03 的验收标准「同一 fixture 必须得到同一色号序列」在跨语言（Rust ↔ TypeScript）下**不可稳定复现**。实现 PR 必须：

1. 在 `crates/bead-core` README（或公开契约文档）中逐条钉死 G1–G8 的选择；
2. 包含下文所有 **MUST** 编号测试（`T-*`）。SHOULD 项可延后，但要在 README 标注。

### 契约缺口（G1–G8，实现前必须钉死）

| # | 缺口 | 审查建议（实现者可另选，但必须文档化 + fixture 锁定） |
|---|------|------|
| G1 | **透明像素语义**：两份文档均未定义 alpha。`Grid<ColorId>` 需要空格表示；BOM/四拆分/判定器如何对待透明格未说明 | alpha ≥ 128 视为不透明，否则为空格（`None`/哨兵）。空格不进 BOM、不进任何步骤、不接收也不发出抖动误差 |
| G2 | **跨语言浮点漂移**：`powf/cbrt/atan2/sin/cos` 在 Rust libm 与 JS `Math` 上末位 ulp 可不同；最近色在近平局处会翻转，直接击穿 B03 的序列一致验收 | ① ΔE 完全相等时 tie-break 取色板索引最小者；② Rust oracle 生成 fixture 时**断言无近平局**：每个像素次优色 ΔE − 最优色 ΔE > 1e-6（见 T-PAR-3） |
| G3 | **像素图路径缺网格提取 oracle**：PLAN 说「像素图：按图中像素块识别」，需要 cell 尺寸 + 相位（offset）检测；WP-B01 第 4 条只要求分类器。若网格提取只活在 B03 的 TS 里，就违反「Rust 包是算法 oracle」原则 | B01 增补公开函数 `detect_grid(image) -> {cell_w, cell_h, offset_x, offset_y}`（或明确声明该逻辑 B03 独有并在 TS 侧单独钉 fixture——不推荐） |
| G4 | **Outline→Infill 的连通分量定义不明**：按同色分量还是按「非空掩码」整体分量？连通性 4 邻接还是 8 邻接？外轮廓/内边界/洞的判定未定义 | 结构支撑语义 ⇒ 在**非空掩码**上做 CCL；分量 4 邻接；洞 = 从网格外边界 4 邻接洪泛不可达的背景；外轮廓 = 与外部背景 8 邻接的分量格；内边界 = 与洞 8 邻接的分量格；一格只归一类，外轮廓优先 |
| G5 | **缩放重采样未指定**：滤波器（box/bilinear）与颜色空间（线性光 vs sRGB 码值）都影响输出色号。B03 若用 canvas `drawImage` 平滑缩放，结果与 Rust 必然不一致 | 两侧手写同一 box（面积平均）滤波；平均在**线性光**空间做（文档化亦可选 sRGB 码值空间，但必须两侧一致并用 T-SCL-5 锁死）；舍入规则钉死（如四舍五入 .5 进位） |
| G6 | **排序 tie-break 全部未定义**：Color-by-Color 同计数色、BOM 排序、替代色同 ΔE、分量顺序 | 一律以色号索引升序 / 分量最上-最左格为第二键；BOM 建议颗数降序 + 色号升序 |
| G7 | **抖动细节未钉**：误差在什么空间累计（sRGB 码值 vs 线性光）？扫描序（经典 raster vs serpentine）？累计值是否夹取？遇透明格如何处理？ | 经典 raster（左→右、上→下，不做 serpentine）；误差按 sRGB 码值 f64 累计、不提前夹取，仅在查最近色前夹到 [0,255]；越界不扩散；透明格既不接收也不中转误差 |
| G8 | **ΔE<3 的边界与 0×0 网格语义**：`<3` 是严格小于（按 WP 字面：是）；空网格/全透明是错误还是空结果 | 严格 `<3`（T-SUB-1 锁边界）；`Grid` 允许全空并产生空 BOM/零步骤；图像管线对 0 尺寸输入返回类型化错误（如 `InvalidDimensions`），一律不 panic |

另注（非缺口）：PLAN 提到六角/圆板、多板拼接、`.pat`/`.gamedev`、实物逆向，均不在 WP-B01/B03 v0 交付内，一致；`Grid` 类型不要把「正方形」写死到无法扩展即可，不作硬性要求。

## 1. CIEDE2000（sRGB→Lab D65 → ΔE00）

### 契约要点

- sRGB 解码：`c ≤ 0.04045 ? c/12.92 : ((c+0.055)/1.055)^2.4`；线性 RGB→XYZ 用 IEC 61966-2-1 的 sRGB/D65 矩阵；XYZ→Lab 白点 D65（Xn=0.95047, Yn=1.00000, Zn=1.08883）。**矩阵常数必须两侧逐位相同**（4 位小数版与由原色推导版在第 4 位就分叉）。
- ΔE00 按 Sharma, Wu & Dalal (2005) 实现注记；易错分支：`G` 因子（C̄⁷/(C̄⁷+25⁷)）、`atan2(b, a')` 且 `a'=b=0 ⇒ h'=0`、|h1'−h2'|>180° 的色相差与均值回卷、只缩放 a' 不动 b'。

### MUST 测试

- **T-DE-1**：Sharma 2005 表内样例，`|ΔE00_计算 − 期望| ≤ 1e-4`。WP 要求 ≥5 组；**至少必须包含下列 8 组**（专打分支），建议直接内嵌全部 34 组：

| # | Lab₁ | Lab₂ | 期望 ΔE00 | 打击点 |
|---|------|------|-----------|--------|
| 1 | (50.0000, 2.6772, −79.7751) | (50.0000, 0.0000, −82.7485) | 2.0425 | 基本路径 |
| 2 | (50.0000, 3.1571, −77.2803) | (50.0000, 0.0000, −82.7485) | 2.8615 | 复用作 T-SUB-1 的 <3 入选 |
| 3 | (50.0000, 2.8361, −74.0200) | (50.0000, 0.0000, −82.7485) | 3.4412 | 复用作 T-SUB-1 的 ≥3 排除 |
| 7 | (50.0000, 0.0000, 0.0000) | (50.0000, −1.0000, 2.0000) | 2.3669 | a'=b=0 的 h'=0 约定 |
| 9 | (50.0000, 2.4900, −0.0010) | (50.0000, −2.4900, 0.0010) | 7.1792 | 色相均值回卷 |
| 13 | (50.0000, −0.0010, 2.4900) | (50.0000, 0.0009, −2.4900) | 4.8045 | 回卷另一象限 |
| 17 | (50.0000, 2.5000, 0.0000) | (73.0000, 25.0000, −18.0000) | 27.1492 | 大差值 + SL/SC/SH |
| 34 | (2.0776, 0.0795, −1.1350) | (0.9033, −0.0636, −0.5514) | 0.9082 | 近黑低 C |

- **T-DE-2**：对称性 `ΔE00(x,y) == ΔE00(y,x)`（至少在表中 9/13 两组上断言）。
- **T-DE-3**：自反性 `ΔE00(x,x) == 0`（含 a=b=0 的灰轴点）。
- **T-SRGB-1**：sRGB→Lab 锚点（容差 ±0.01，前提是矩阵按上文钉死）：

| RGB (u8) | 期望 L* | 期望 a* | 期望 b* |
|----------|---------|---------|---------|
| (0,0,0) | 0.0000 | 0.0000 | 0.0000 |
| (255,255,255) | 100.0000 | ~0 | ~0 |
| (255,0,0) | 53.2408 | 80.0925 | 67.2032 |
| (0,255,0) | 87.7347 | −86.1827 | 83.1793 |
| (0,0,255) | 32.2970 | 79.1875 | −107.8602 |
| (128,128,128) | 53.5850 | ~0 | ~0 |

（白/灰的 a*, b* 因矩阵舍入不严格为 0，容差放 ±0.01；若实现将白点取自矩阵行和，可断言精确 0——两选一，文档化。）

## 2. 色板映射（generic-5mm）

### MUST 测试

- **T-PAL-1**：色板内每个色号的 RGB 输入映射回自身（ΔE00=0 恒等）。
- **T-PAL-2**：tie-break 锁定——构造含重复 RGB 的测试色板（索引 3 与 7 同色），输入该 RGB 必须返回索引 3（G2/G6 规则）。
- **T-PAL-3**：健壮性 property 测试——固定种子随机 ≥1000 个 RGB(u8)，输出恒为合法色板索引，不 panic。

fixture 建议：`generic-5mm` 以数据文件（JSON/TOML）提供并在文档标明「文档化通用板，非任何真实品牌」；条目含 `id`、`display_name`、`rgb`。

## 3. Floyd–Steinberg

### MUST 测试

- **T-FS-1**：抖动关闭 ⇔ 逐像素独立最近色映射，两条路径输出全等。
- **T-FS-2**：权重与扫描序锁定——2×2 全 (128,128,128)、色板 {黑 (0,0,0)、白 (255,255,255)}。按 G7 契约手推：(0,0) 量化为白，误差 −127 按 7/16 右、5/16 下、1/16 右下扩散，最终应得棋盘 `[白,黑;黑,白]`。以 Rust oracle 输出冻结为 fixture，两侧断言全等。
- **T-FS-3**：1×8 灰阶梯（0,32,64,…,224）+ 黑白板 → 冻结输出序列；同时覆盖「只能向右扩散」与最右像素误差丢弃。
- **T-FS-4**：边界不越界——1×1、1×N、N×1、右下角像素均无 OOB、无 panic。
- **T-FS-5**：输出封闭性——任意输入（含误差累计越出 [0,255] 的构造用例）输出只含色板色号（WP「超出色板时仍量化到最近色」的落地断言）。
- **T-FS-6**：均值守恒——64×64 全 (128,128,128) + 黑白板，输出黑白占比与 128/255 偏差 ≤ 2%（在 G7 选定的累计空间内成立；锁住「误差没被悄悄夹没」）。
- **T-FS-7**：透明格隔离——中央带透明洞的 fixture：洞不接收误差、不中转误差、不出现在输出步骤；输出冻结。

## 4. 像素图判定（PixelArt | Photo + 置信度）

### 契约要点

规则启发式（网格周期性 + 独特色数），禁外部视觉 API。**特征与阈值公式必须写进契约**，否则 B03 无法对齐（分类翻转 ⇒ 走错管线 ⇒ 色号序列必不同）。

### MUST 测试

- **T-CLS-1**：合成像素图——24×24、12 色 sprite 经 8× 最近邻放大到 192×192 → `PixelArt` 且置信度 ≥ 0.8。
- **T-CLS-2**：照片样张——256×256 平滑双向渐变（独特色 ≥ 10000）→ `Photo`。
- **T-CLS-3**：置信度有界——1×1、单色图、噪声图、全透明图上置信度均 ∈ [0,1]，无 NaN/除零（全透明 ⇒ 不透明像素计数为 0 是除零高危点）。
- **T-CLS-4**：全透明与单色图的判定结果在契约中钉死（建议：`PixelArt`，置信度取文档化默认值），测试断言之。
- **T-GRID-1**（随 G3 增补的 `detect_grid`）：对 T-CLS-1 的 8× 放大图断言 `cell_w = cell_h = 8`、`offset = (0,0)`；对带 3px 相位偏移的变体断言 `offset = (3,3)`。

SHOULD：轻度 JPEG 噪声下的近周期网格仍判 `PixelArt`（鲁棒性，可 round 2）。

## 5. 框定 / 缩放（三模式）

### MUST 测试

- **T-SCL-1**：固定板——56×56 输入、每 2×2 块内颜色均匀 → 28×28 输出与逐块颜色一一对应（box 滤波恒等用例）。56×56 板同理。
- **T-SCL-2**：按比例适配的舍入锁定——`100×50 → 28×14`、`50×100 → 14×28`、`29×29 → 28×28`、`3000×1 → 28×1`（最小维夹到 1）。舍入规则文档化并被这些用例锁死。
- **T-SCL-3**：手动缩放 + 裁剪——crop 全在图内正常；部分越界按契约（建议：夹取 + 越界区透明填充）；完全在图外 → 类型化错误。三种情形各一 fixture。
- **T-SCL-4**：参数校验——`scale ≤ 0`、零面积 crop、0 尺寸图像 → 类型化错误（G8），不 panic。
- **T-SCL-5**：重采样空间锁定（G5 判据用例）——2×1 图 [黑 (0,0,0)、白 (255,255,255)] 缩到 1×1：线性光平均 ⇒ 输出码值 ≈ 188（0.5 线性 → sRGB 编码 ≈ 0.7354×255，按钉死的舍入规则冻结精确值）；sRGB 码值平均 ⇒ 128。实现选定其一后本用例双侧断言精确值。

## 6. 四模式步骤拆分（输入 `Grid<ColorId>`）

### 全模式共同 MUST

- **T-SPL-0**：划分性质（property 测试，固定种子随机含透明格网格 ≥100 个）——四模式各自：所有步骤覆盖的格 = 全部非空格，无重复、无遗漏、无越界、不含透明格。
- **T-SPL-1**:0×0 网格与全透明网格 → 四模式均 0 步骤、不 panic。
- **T-SPL-2**：确定性——同一网格跑两遍，步骤序列逐字节相等。

### Color-by-Color

- **T-CBC-1**：计数 {A:1, B:5, C:5}（B 的色号索引 < C）——默认升序 → 步骤顺序 [A, B, C]；切降序 → [B, C, A]（同计数仍按色号索引升序，G6）。
- **T-CBC-2**：单色网格 → 恰 1 步，格序行优先（左→右、上→下）。

### Tile（固定 28×28）

- **T-TIL-1**：56×56 满网格 → 恰 4 个 tile，顺序 (0,0)→(28,0)→(0,28)→(28,28)；tile 内格序行优先。
- **T-TIL-2**：30×29 网格 → 部分 tile 尺寸冻结为 (28×28)、(2×28)、(28×1)、(2×1)（不补齐、不填充）；其中一个 tile 全透明的变体 → 该 tile 不产生步骤（跳过语义文档化并锁定）。

### Outline→Infill（按 G4 钉死后）

- **T-OUT-1**：4×4 实心块 → 外轮廓 12 格，再内部 4 格；顺序冻结。
- **T-OUT-2**：7×7 环（挖空中心 3×3）→ 外轮廓 24 格（最外圈）、内边界 16 格（贴洞一圈）、填充 0 格；1 格宽环的变体（5×5 挖 3×3）中外轮廓与内边界重合 → 断言每格只出现一次且归外轮廓（G4 的「外轮廓优先」）。
- **T-OUT-3**：仅对角相触的两格 → 4 邻接下为 2 个分量（锁死连通性选择；若实现选 8 邻接则此 fixture 期望反转并同步改文档）。
- **T-OUT-4**：两个不相交色块 → 分量顺序按「最上、再最左」首格排序（G6）。

### Row-by-Row

- **T-ROW-1**：中间一整行透明的 fixture → 该行不产生步骤；行序自上而下，行内自左而右；每非空行恰一步（粒度文档化并由此用例锁定）。

## 7. BOM

### MUST 测试

- **T-BOM-1**：冻结网格 → 精确 (色号, 显示名, 颗数) 行集；且 Σ颗数 == 非空格总数（与 T-SPL-0 同源不变量）。
- **T-BOM-2**：0×0 / 全透明 → 空 BOM；单色网格 → 恰 1 行。
- **T-BOM-3**：排序锁定（G6，建议颗数降序、同数色号升序），构造两色同颗数 fixture 断言。

## 8. 替代色（库存内 ΔE00 < 3）

### MUST 测试

- **T-SUB-1**：边界严格性——在 Lab 级 API 上用 Sharma 第 2 组（ΔE=2.8615 → **入选**）与第 3 组（ΔE=3.4412 → **排除**）；另用 oracle 冻结一对 RGB 色使 ΔE ≈ 2.99 入选、≈ 3.01 排除，钉死严格 `<3`（G8）。
- **T-SUB-2**：排序——候选按 ΔE 升序，同 ΔE 按色号索引升序（G6）；确定性双跑全等。
- **T-SUB-3**：空结果语义——库存内无 ΔE<3 候选 → 空列表（非错误）；库存含与缺色完全相同的 RGB → 该色 ΔE=0 排第一（是否把「自身在库存」视为不缺由上层判断，核心函数不特判——文档化）。

## 9. B01 ↔ B03 一致性（parity，B03 验收核心）

- **T-PAR-1**：**共享 fixture 文件**——JSON 格式：原始 RGBA u8 数组 + 全参数（板型、框定、抖动开关、色板）→ 期望色号网格 + 四模式步骤序列 + BOM。同一份文件同时被 `cargo test` 与 `vitest` 消费（提交一份，或双份 + 校验和一致性测试），色号序列**逐元素全等**。至少覆盖：像素图路径 ×1、照片路径（抖动开/关各 1）、含透明 ×1。
- **T-PAR-2**：parity 路径**禁止 PNG 解码差异**——parity fixture 一律用原始 RGBA 数组，不走 png/jpg 解码（浏览器会应用 ICC 色彩配置、`drawImage` 会重采样，Rust `image` crate 不会——这是已知的序列击穿源）。B03 上传路径的 PNG→RGBA 提取需文档化 ICC 中和策略（如 `createImageBitmap(..., {colorSpaceConversion:'none'})` 或等价手段），并单测一张已知 PNG 的前 N 像素字节。
- **T-PAR-3**：**近平局哨兵**（G2）——Rust oracle 生成/校验每个 parity fixture 时断言：每像素次优色板 ΔE − 最优 ΔE > 1e-6；违者换 fixture。该断言本身作为 oracle 侧测试提交。
