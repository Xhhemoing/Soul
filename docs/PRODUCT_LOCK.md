# Soul 产品锁定

状态：2026-08-24 按作者当面定义重锁，并经 2026-08 三轮计划评审收窄 v0.1；2026-08-25 补入已冻结的灵魂层算法口径（见「灵魂层算法（v0.1）」）。
未标 `ASSUMPTION` 的条目视为已拍板。`docs/PRODUCT_LOCK.md` 是唯一产品权威，禁止再建 `PRODUCT.md`。
算法口径（判档规则、常量、用户可见话术）的唯一权威是 `docs/algorithms/DECISION.md`（`ALGO_FROZEN`）：本文件只锁产品承诺，不复抄常量数值。

## 一句话

Soul 是灵魂级个人软件：根据你授权的社交媒体档案、电脑（后期含手机）操作和日常生活记录，在本机复刻一个电子版的你——含人格、记忆、心理倾向和人脉图——并以此帮你处理电脑/手机事务、起草回复、执行简单工作、分析生活中的人与事。Windows 本地部署优先；本机采集与浅层处理，云端仅在你显式开启后做深度分析。行为数据可在你授权下用于行为预测研究。

## 作者原意（不得稀释）

1. 根据社交媒体数据、电脑/手机操作，以及后期的学习情况和日常生活记录，复刻电子版的你。
2. 复刻人脉图。
3. 懂得你的内心、性格、朋友、喜好和几乎一切。
4. 帮你处理电脑/手机中的很多问题：回复消息、执行简单工作等。
5. 帮你分析生活中的人与事，做完美辅助。
6. 有人格、记忆、心理。
7. 收集行为数据，用于行为预测的学习与研究；后期产品也往这个方向进化。
8. Windows 本地部署优先。（作者 2026-09-04 澄清：Windows 是 v0.1 的开发与测试平台，不是唯一目标；核心后续部署于 Linux / macOS / Windows，接入端含 macOS / Linux / Windows / Android，用于数据采集与结果呈现。v0.1 边界表不变。见 DECISIONS D65。）
9. 后期：手机和电脑的本地数据收集与简单处理；云端 AI 深度分析。
10. 其余未指定问题由项目自主决定。

## 不是什么

- 不是通用 ChatGPT 桌面壳。
- 不是虚构桌宠、虚拟恋人或角色扮演伴侣。电子版的你 ≠ 虚构角色。
- 不是无授权爬取他人社交账号的工具。
- 不是默认把原始日记/聊天/屏幕上传云端的监控软件。
- 不是无人值守 AutoGPT，也不是可永久允许一切的系统管理员。
- 不是临床医学产品，不给出精神疾病诊断。
- 不是 pi-sparkle 插件。

## 产品两层

| 层 | 作用 |
|---|---|
| 灵魂层 | 人格、价值观、心理工作模型、自传记忆、人脉图、偏好。用户可查看和纠正。 |
| 代理层 | 在灵魂层约束下，经人在回路审批，处理本机（后期手机）任务：起草回复、简单工作、整理、提醒、分析。 |

研究层是第三条轨道：本机事件库 → 可选脱敏预览 → 后期云端行为预测。没有单独同意，研究轨道不得把原始内容送出本机。v0.1 研究轨道只预览、不写导出文件。

## 灵魂层算法（v0.1）

判档规则、常量与用户可见话术的**唯一权威**是 `docs/algorithms/DECISION.md`（`ALGO_FROZEN`，2026-08-24 冻结）；话术在 `docs/algorithms/COPY_ZH.md`，落选者墓碑在 `docs/algorithms/REJECTED.md`。本节只写产品面承诺，**不复抄任何常量数值**——同一个数字出现在两处即算双源缺陷。

| 面 | v0.1 形态 | 产品面含义 |
|---|---|---|
| 人脉关系强度 | **T4D**，唯一权威判档 | 强/中等/弱三档只由**一对一**往来判定。群聊往来照常展示，并作为「这个人没有从生活中消失」的近因证据，但不制造档位 |
| 特质轴 | **A0**：问卷 + 本人纠正锁定 | 轴位置来自你答的题和你本人的纠正。纠正即锁定，之后的推断只被记录，不改动你的设定 |
| 升档规则 | **A1**：A0 内部的 `TwoKindsAcrossDays` | 要两种不同来源、且跨不同自然日才升档。v0.1 只有问卷一种来源，所以**它永不触发是预期行为**，不是缺陷，也不是待办 |
| 单人人事摘要 | **A2**，纯渲染器 | 只渲染 T 族已经算好并随结构携带的档位与计数；源码级禁止第二套阈值，也禁止自行从证据推导一对一/群聊分列 |

产品面必须同时成立的三条：

1. **档位不是分数。** 用户可见文本只有「强 / 中等 / 弱」三个词，且每个数字用户都能自己数出来（往来次数、自然日数、整数天数差、日期）。禁止分数、百分位、排名、权重、算法名（禁词表见 `COPY_ZH.md` 第 0 节）。这是 D22「方向轴而非量表」在人脉面的同一条承诺。
2. **时间口径来自数据，不来自墙钟。** 一次重建全库只用一个 `as_of`；不按每个人各自的最后时间戳算——那会让休眠多年的关系假装还很强。
3. **降档与「你们最近半年没有往来」是同一个阈值。** 用户读到那句话时，档位必然已经降下，两者不得同屏矛盾。「半年」「一年」各自对应 `DECISION.md` 常量表里的一个天数常量，本文件不复抄数值。

已知代价（如实入档，产品接受，禁止静默修补）：

- 只在群里说过话、从未一对一 → 判弱。自愈便宜：双向各补够常量表规定的一对一次数即回中等。群里的往来仍如实展示。
- 长期休眠之后昨天一来一回，可以回到强（`DECISION.md` §4.2）。**禁止**为此加第三道降档门；不满意只能走 `DECISION.md` 第 5 节回退链，并在 `docs/DECISIONS.md` 留痕。
- 一对一停了很久、群聊仍然活跃 → 不降档（§4.3 已定价）。

本节**不新增 v0.1 切片项**，只是把切片第 3、6 两条里「推断带证据与证据档」「单人人事分析摘要」的算法口径钉到冻结决议上。算法实现活在 `crates/soul-algo-tie` 与 `crates/soul-algo-trait`：纯函数、不读墙钟、不落库；禁止把 SQLCipher、Tauri 或任何 HTTP 依赖拉进这两个 crate（依赖箭头恒为应用 → 算法 crate）。

## 出网分级（E0 / E1 / L）

| 类 | 定义 | v0.1 |
|---|---|---|
| E0 业务出网 | 遥测、更新、许可、项目方云、深度分析 HTTP | **无代码路径**，恒 deny |
| E1 用户指向 | 用户填写的 OpenAI 兼容端点 | 未配置=关；仅用户触发的生成 |
| L 本地回环 | UI↔core、本地模型 | 允许，只绑 loopback |

「零业务出网」= soul.exe / soulcore / 子进程的非回环连接数为 0（未配 E1），或仅指向用户填写的 E1 主机（已配）。OS 自身流量不计。

## 第三人正文默认占位

- `self` / `third_party` / `mixed`（按 third_party 处理）。
- 进入 E1 的请求体必须经 redactor。第三人正文默认换成占位符；姓名/账号同样占位。
- 单次豁免：二次确认后可把**本条**对话原文送 E1；不记住；审计只记豁免事实不记正文。研究预览无豁免。
- 可测：fixture 中第三人原文任意 ≥8 字连续子串不得出现在默认 E1 请求体。

## 数据面

- 主库 `%LOCALAPPDATA%\Soul\soul.db`（加密 SQLite）。
- 密钥：DPAPI 保护 KEK → DB DEK → 每遗忘单元内容密钥。
- 遗忘 = 销毁内容密钥 + 删除/墓碑引用 + 派生推断降为 orphaned。不承诺 SSD 物理擦除；UI 必须如实写。
- 审计独立、只追加、无正文。可保留孤立本地 UUID。

## v0.1 最小垂直切片

在干净 Windows 11 x64 上必须同时证明灵魂层，以及代理层的只读安全路径：

1. 安装、托盘、灵魂向导（权限默认全关）。
2. 问卷 + `soul-import-v1` JSONL（见 `docs/schemas/soul-import-v1.schema.json`）/ Telegram `result.json`。
3. 可编辑档案（特质轴/偏好/边界）+ 人脉图 v0；推断带证据与证据档。
4. 用户纠正锁定，后续推断不覆盖；起草语气立即改变。
5. 自传记忆 CRUD + 遗忘（销毁内容密钥）+ 影响面预览。
6. 单人人事分析摘要（无 key 时统计降级，禁止诊断词）。
7. 可选前台应用采集；关闭后 1 秒内无新事件；未同意时事件数为 0。
8. 粘贴消息按档案语气起草，不发送；默认 E1 请求体第三人正文已占位。
9. 授权目录后只读扫描并生成整理计划预览；v0.1 **不执行写**；未授权路径 100% 拒绝。
10. 研究导出只预览；第三人行数为 0；不写文件。
11. 云端开关「尚未启用」；零 E0。
12. 审计覆盖采集、导入、推断、纠正、记忆、遗忘、起草、E1、文件计划、拒绝。
13. CI + 安装 smoke。

## 不可协商约束

1. Windows 本地优先；日常不提权。
2. 采集默认关；未同意事件数为 0。
3. 社交数据只走官方导出/手动导入（v0.2 起可加 OAuth）；永不抓取。
4. 出站消息与不可逆操作必须人在回路；v0.1 禁止代发与文件写执行。
5. 档案可查看、纠正、导出、彻底遗忘（销毁内容密钥）；推断必须有证据。
6. 第三人数据默认不出本机；E1 默认占位；研究预览第三人行数为 0。
7. 研究与助手分离；研究只吃 derived/aggregate。
8. 外部内容不可信，不能变成指令或授权；必须有注入红线用例。
9. 未知动作拒绝；计划哈希变化拒绝；能力令牌一次性。
10. 不做虚构恋人，不做不可纠正黑盒。
11. 出网按 E0/E1/L；E0 无代码路径。
12. 审计无内容；审计不得阻止遗忘。
13. 人脉档位与特质轴的口径以 `ALGO_FROZEN` 为准；产品面不得另立第二套阈值，不得为 F04c 加第三道降档门，改判只走 `DECISION.md` 回退链并在 `DECISIONS.md` 留痕。
