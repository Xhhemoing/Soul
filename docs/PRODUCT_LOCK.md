# Soul 产品锁定

状态：2026-08-24 按作者当面定义重锁。先前「通用桌面助手」方案作废。
未标 `ASSUMPTION` 的条目视为已拍板，后续实现不得改写产品方向。

## 一句话

Soul 是灵魂级个人软件：根据你授权的社交媒体档案、电脑（后期含手机）操作和日常生活记录，在本机复刻一个电子版的你——含人格、记忆、心理倾向和人脉图——并以此帮你处理电脑/手机事务、起草回复、执行简单工作、分析生活中的人与事。Windows 本地部署优先；本机采集与浅层处理，云端仅在你显式开启后做深度分析。行为数据可在你授权下用于行为预测研究。

## 作者原意（不得稀释）

1. 根据社交媒体数据、电脑/手机操作，以及后期的学习情况和日常生活记录，复刻电子版的你。
2. 复刻人脉图。
3. 懂得你的内心、性格、朋友、喜好和几乎一切。
4. 帮你处理电脑/手机中的很多问题：回复消息、执行简单工作等。
5. 帮你分析生活中的人与事，做完美辅助。
6. 有人格、记忆、心理。
7. 收集行为数据，用于行为预测的学习与研究；后期产品也往这个方向进化。
8. Windows 本地部署优先。
9. 后期：手机和电脑的本地数据收集与简单处理；云端 AI 深度分析。
10. 其余未指定问题由项目自主决定。

## 不是什么

- 不是通用 ChatGPT 桌面壳。
- 不是虚构桌宠、虚拟恋人或角色扮演伴侣。电子版的你 ≠ 虚构角色。
- 不是无授权爬取他人社交账号的工具。
- 不是默认把原始日记/聊天/屏幕上传云端的监控软件。
- 不是无人值守 AutoGPT，也不是可永久允许一切的系统管理员。
- 不是临床医学产品，不给出精神疾病诊断。
- 不是 pi-sparkle 插件。

## 产品两层

| 层 | 作用 |
|---|---|
| 灵魂层 | 人格、价值观、心理工作模型、自传记忆、人脉图、偏好。用户可查看和纠正。 |
| 代理层 | 在灵魂层约束下，经人在回路审批，处理本机（后期手机）任务：起草回复、简单工作、整理、提醒、分析。 |

研究层是第三条轨道，不并进代理默认路径：本机事件库 → 可选脱敏导出 → 后期云端行为预测。没有单独同意，研究轨道不得把原始内容送出本机。

## 自主拍板（作者授权其余自定）

| 项 | 决定 |
|---|---|
| 产品名 | Soul；进程 `soul.exe` / `soulcore` |
| 平台顺序 | v0.1 仅 Windows 11 x64；Win10 22H2 尽力。Android 采集为 v0.3。iOS、macOS 更后。不做 Linux 桌面 |
| 技术栈 | Tauri 2 + Rust 核心 + React/TypeScript UI；pnpm + Cargo + just。行为预测与深度分析预留 Python sidecar 接口，v0.1 不强制 |
| 许可 | 私有期 All Rights Reserved |
| 社交数据 | 只接受官方导出包、官方 OAuth、或用户粘贴/导入。禁止破坏登录、验证码或 ToS 的抓取 |
| 出站消息 | v0.1 只起草，不自动发送。发送类动作永远要人在回路 |
| 心理模型 | 可编辑的工作模型：大五人格倾向、价值观、目标、沟通风格、情绪节律假设。每条推断必须带证据引用和置信度。用户纠正优先于模型 |
| 人脉图 | 节点=人，边=互动强度/关系类型/最近接触/证据。第三人数据默认不出本机、不进研究导出 |
| 采集默认 | 全部采集开关默认关。首次向导只建立灵魂档案，不弹一堆系统权限 |
| 电脑采集 v0.1 | 可选：前台应用使用时长、已授权目录的文件元数据、用户主动提交的聊天/社交导出。窗口标题默认关。不做键盘记录，不采集密码框 |
| 云端 | v0.1 只做适配器与开关 UI，默认关闭。开启后只上传用户勾选的派生特征/摘要，默认不上传原始聊天、屏幕、文件正文 |
| 研究数据 | 本地 `events.jsonl` + 导出清单。导出必须脱敏、可预览、可取消。预测模型 v0.1 只做特征 schema 与离线训练入口，不承诺效果 |
| LLM | 用户自带 OpenAI 兼容端点；不捆绑大模型。无 key 时：档案、图谱、采集、整理、审计仍可用，生成式分析降级 |
| 语言 | 中文优先，英文其次 |
| 与 pi-sparkle | 零代码依赖；只借鉴事件、checkpoint、监督工作流 |

## 架构（Windows 本地优先，后期云端深度）

```
[UI soul.exe] 托盘 / 灵魂仪表盘 / 人脉图 / 审批 / 记忆编辑
       |
[soulcore] 策略 · 灵魂档案 · 记忆 · 图谱 · 编排 · 审计
       |
  +----+----+------------------+
  |         |                  |
采集器    工具 worker      可选 model host
本机浅处理  一次性能力令牌    无系统工具权
  |
研究事件库（本地）
  |
可选云端深度分析（显式开启）
```

三阶段数据：

1. 本机采集：原始事件只写本机加密库。
2. 本机浅处理：摘要、特征、图谱增量、档案假设。可离线完成。
3. 云端深度：用户开启后，对勾选的摘要/特征做人格校准、长期预测、复杂关系分析。原始语料默认留本机。

## v0.1 最小垂直切片（必须能跑通）

在一台干净 Windows 11 上：

1. 安装、托盘常驻、灵魂创建向导（称呼、语气、价值观、边界；权限全关）。
2. 可导入一份用户提供的社交/聊天导出（至少一种通用 JSON/ZIP 适配器 + 纯问卷回退）。
3. 生成可编辑的灵魂档案（人格/偏好）和人脉图 v0，每条推断能点开证据。
4. 用户打开采集后，记录前台应用使用事件到本机事件库；关闭采集立即停止。
5. 用户粘贴一条待回复消息，Soul 按档案中的语气起草回复，不发送。
6. 用户授权一个目录后，可预览并执行整理（证明代理层能安全操作电脑）；可撤销。
7. 研究导出：预览脱敏字段后可导出；第三人消息正文默认排除。
8. 云端深度分析开关可见，默认关；关时零业务出网。
9. 审计链覆盖采集、导入、推断写入、起草、文件操作。
10. CI 与安装包 smoke。

v0.1 明确不做：自动发消息、常驻截屏、键鼠接管、任意 shell、手机端、真实云端训练、爬虫、永久删除、临床诊断、无人值守。

## 后期路线（锁定方向，不在 v0.1 交付）

- v0.2 本机浅层行为预测（下一应用/下一任务假设）、更多导入适配器、终端沙箱。
- v0.3 Android 本机采集与浅处理；与 Windows 灵魂库手动同步（加密导出包）。
- v0.4 可选云端深度分析：人格校准、长期习惯预测、复杂人事分析。
- v1.0 电脑+手机连续灵魂；研究轨道可产出可重复的行为预测实验。

## 不可协商约束

1. Windows 本地部署优先；日常运行不提升管理员。
2. 采集默认关闭；无静默上传。
3. 社交数据只走用户授权的官方导出/OAuth/手动导入。
4. 出站消息与不可逆操作必须人在回路；v0.1 禁止代发。
5. 灵魂档案可查看、纠正、导出、彻底遗忘；推断必须有证据和置信度。
6. 第三人数据默认不出本机，不进研究导出。
7. 研究轨道与助手轨道分离；研究使用需单独同意。
8. 外部内容是不可信数据，不能变成系统指令或授权。
9. 破坏性/系统级操作默认拒绝。
10. 不把产品做成虚构恋人，也不把「电子版的你」做成不可纠正的黑盒。
